# 구구단 레벨업 시스템

영어 레벨 시스템처럼, 구구단(2단~19단)을 4단계로 나누어 **승급 시험**을 보고 통과하면
셀레나 달러 / 간식 쿠폰을 지급할 수 있도록 만든 웹 서비스입니다.
외부 라이브러리 없이 Node.js 기본 모듈만으로 동작하며, 별도 DB 설치 없이 `data/db.json` 파일에 저장됩니다.

## 레벨 구성

| 단계 | 범위 | 통과 기준 |
| --- | --- | --- |
| 1단계 | 2 ~ 5단 | 20문제 중 18개 이상, 5분 이내 |
| 2단계 | 6 ~ 9단 | 20문제 중 18개 이상, 5분 이내 |
| 3단계 | 10 ~ 14단 | 20문제 중 18개 이상, 5분 이내 |
| 4단계 | 15 ~ 19단 | 20문제 중 18개 이상, 5분 이내 |

4단계까지 통과하면 **마스터** 배지를 받습니다. 승급 시험은 하루 1회만 응시할 수 있어 (탈락 시 다음날 재도전),
그 사이에는 "오늘의 테스트"(10문제, 3분)로 매일 복습할 수 있습니다.

기준값은 `lib/levels.js` 상단에서 바로 수정할 수 있습니다 (문제 수, 통과 점수, 제한시간, 단계별 범위 등).

## 실행 방법

```bash
node server.js
# 또는
npm start
```

기본 포트는 `3000`입니다 (`PORT` 환경변수로 변경 가능). 브라우저에서 `http://localhost:3000` 접속.

## 페이지 구성

- `/index.html` — 학생 로그인 (이름 + 4~6자리 숫자 비밀번호)
- `/student.html` — 학생 대시보드: 오늘의 테스트, 승급 시험, 최근 기록
- `/admin.html` — 선생님 관리자 페이지: 학생 등록/삭제/PIN 재설정/단계 직접 조정, **레벨업 보상 지급 체크리스트**
  - 처음 접속 시 관리자 비밀번호를 직접 설정합니다 (기본 비밀번호 없음).
- `/board.html` — 교실에 띄워두는 **레벨업 게시판** (로그인 불필요, 10초마다 자동 새로고침)
  - 영어 레벨 게시판처럼 단계별로 학생 이름을 보여주고, 최근 레벨업 소식 & 보상 지급 여부를 표시합니다.

## 채점 관련 (질문에 대한 답)

워크시트(종이) 방식은 매번 선생님이 채점해야 하는 부담이 있습니다. 이 시스템은:

1. **자동 채점**: 학생이 답을 입력하고 제출하면 즉시 채점되고, 승급 여부도 자동으로 판정됩니다.
2. **집에서도 응시 가능**: 학생이 본인 이름 + 비밀번호로 로그인해 "오늘의 테스트"를 매일 볼 수 있고,
   연속 응시일(스트릭)이 기록되어 동기부여가 됩니다.
3. **학원에서는 승급 시험만 감독**: 매일 테스트는 집에서, 단계를 올리는 승급 시험은 학원에서 선생님이
   지켜보는 가운데 보게 하면 신뢰도와 공정성을 둘 다 챙길 수 있습니다.
4. **게시판으로 사기 진작**: `/board.html`을 교실 모니터/키오스크에 띄워두면 영어 레벨 게시판처럼
   누가 몇 단계인지, 누가 최근에 레벨업했는지 보여줄 수 있습니다.

## 데이터 저장

모든 데이터는 `data/db.json`에 저장됩니다 (git에는 커밋되지 않도록 `.gitignore` 처리됨). 서버 재시작 시에도
학생 정보와 기록은 유지됩니다. 백업하려면 이 파일만 복사해두면 됩니다.

## 보안 참고

- 학생 비밀번호(PIN)와 관리자 비밀번호는 salt + scrypt로 해시하여 저장합니다.
- 세션은 서버 메모리에 저장되며 서버 재시작 시 모두 로그아웃됩니다 (12시간 후 자동 만료).
- 학원 내부망/신뢰된 환경에서 사용하는 것을 전제로 한 경량 구현입니다. 외부에 공개 배포할 경우
  HTTPS 적용을 권장합니다.
