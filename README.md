# 구구단 레벨업 시스템

영어 레벨 시스템처럼, 구구단(2단~19단)을 4단계로 나누어 **승급 시험**을 보고 통과하면
셀레나 달러 / 간식 쿠폰을 지급할 수 있도록 만든 웹 서비스입니다.

**Next.js + Prisma + Postgres** 구조로 만들어져 있어 **Vercel(무료 Hobby 플랜) + Neon(무료 Postgres)** 에
추가 비용 없이 배포할 수 있습니다. 집에서도 학생이 자기 이름으로 로그인해서 매일 테스트를 볼 수 있도록,
데이터는 서버 컴퓨터의 파일이 아니라 클라우드 Postgres에 저장됩니다.

## 레벨 구성

| 단계 | 범위 | 문항 수 | 통과 기준(90%) | 제한시간 |
| --- | --- | --- | --- | --- |
| 1단계 | 2 ~ 9단 | 48문제 (단마다 6문제, 6~9단 교차 곱셈 등 자주 틀리는 조합 필수 포함) | 44개 이상 | 약 6.4분 |
| 2단계 | 10 ~ 13단 | 36문제 (단마다 ×1~9 전체) | 33개 이상 | 약 7.2분 |
| 3단계 | 14 ~ 16단 | 27문제 (단마다 ×1~9 전체) | 25개 이상 | 약 5.9분 |
| 4단계 | 17 ~ 19단 | 27문제 (단마다 ×1~9 전체) | 25개 이상 | 약 6.3분 |

4단계까지 통과하면 **마스터** 배지를 받습니다. 승급 시험은 하루 1회만 응시할 수 있어 (탈락 시 다음날 재도전),
그 사이에는 "오늘의 테스트"로 매일 복습할 수 있습니다.

기준값은 `lib/levels.ts` 상단에서 바로 수정할 수 있습니다 (단마다 문항 수, 자주 틀리는 곱셈 목록, 통과율, 제한시간, 단계별 범위 등).

### 오늘의 테스트 문항 수

레벨(단계) 기준으로 자동 산정됩니다 — 지금까지 배운 단 수 × 3문제, 최소 15문제 ~ 최대 30문제로 제한됩니다
(예: 1단계=8개 단이면 24문제). 아래 "학생별 출제 범위 직접 설정"으로 관리자가 재정의하면 그 설정이 우선합니다.

### 학생별 출제 범위 직접 설정 (막 시작한 학생용)

레벨 시스템(2~9단 등 고정 범위)은 승급 시험 기준으로는 유지하되, **"오늘의 테스트"는 관리자가 학생마다
직접 범위를 지정**할 수 있습니다. `/admin`의 학생 상세 화면에서:

- 출제할 단(2~19단)을 체크박스로 선택 — 이제 막 시작한 학생이라면 2단, 3단만 체크해서 좁혀줄 수 있어요
- 문항 수를 직접 입력 (비워두면 선택한 단 수 기준 자동 계산)
- "문제 중복 가능" 체크 — 선택한 단 조합의 전체 곱셈 조합 수보다 문항 수를 더 많이 요청하면, 체크 시엔
  같은 문제가 반복 출제되고 체크 안 하면 조합 수만큼으로 문항 수가 자동으로 잘립니다
- "기본값으로 되돌리기"를 누르면 커스텀 설정이 사라지고 다시 레벨 기준 자동 범위로 돌아갑니다

### 오답 다시 풀기

학생의 모든 응시 기록(오늘의 테스트/승급시험/오답 재테스트)에서 각 문제(a×b)의 **가장 최근 결과**를 추적해서,
마지막으로 틀렸던 문제만 모아 "오답 노트"로 관리합니다. 학생 대시보드에 오답이 하나라도 있으면
**"🔁 오답 다시 풀기"** 카드가 나타나고, 하루 1회 제한 없이 몇 번이든 다시 풀 수 있습니다. 정답을 맞히면
그 문제는 오답 노트에서 빠지고, 다시 틀리면 다시 들어갑니다 — 완전히 사라질 때까지 반복할 수 있습니다.
관리자 화면에서도 학생별로 "현재 오답 노트 N개"를 바로 확인할 수 있습니다.

또한 **오늘의 테스트를 새로 시작할 때마다, 지금까지 틀린 채로 남아있는 문제는 자동으로 그날 문항에
강제로 포함**됩니다 (예: 어제 틀린 문제가 3개면, 오늘 테스트에는 그 3개가 반드시 들어가고 나머지는
평소대로 채워집니다). 그래서 "오답 다시 풀기"를 따로 안 하더라도 매일의 테스트 자체가 자연스럽게
복습이 되도록 설계했습니다.

### 학부모 리포트 (기간 선택 자동 생성)

`/admin`의 학생 상세 화면에서 "학부모 리포트 보기"로 이동하면, **시작일~종료일을 선택**해서 그 기간의
학습 이력을 자동으로 정리한 리포트를 생성할 수 있습니다.

- **부드러운 말투의 자동 서술**: 출석률, 정답률 추이(기간 초반 대비 후반 비교), 풀이 소요시간 변화,
  오답 재테스트 현황, 레벨업 여부 등을 바탕으로 학부모가 읽기 편한 문단 형태의 요약을 자동 생성합니다
  (`lib/reportStats.ts`의 `buildNarrative()` — 외부 AI 호출 없이 통계 기반 템플릿으로 생성됩니다)
- 서술 아래에는 출석률/정답률/추이/오답 등 핵심 지표를 숫자로도 함께 보여주고, 기간 내 일자별 점수·소요시간
  표와 레벨업 이력도 함께 정리됩니다
- "인쇄 / PDF 저장" 버튼으로 그대로 인쇄하거나 PDF로 저장해 학부모에게 전달할 수 있습니다

### 학원 이름 표시

학생 로그인 화면, 관리자 화면, 학부모 리포트에 학원 이름이 공통으로 표시됩니다. 이름은
`lib/branding.ts`의 `ACADEMY_NAME` 값 하나만 고치면 전체에 반영됩니다.

### 승급 시험 자격 기준

바로 승급 시험을 볼 수 있는 게 아니라, 아래 두 조건을 **모두** 만족해야 시험 버튼이 열립니다 (`lib/levels.ts`의
`READINESS_CONFIG`에서 조정 가능, 기본값):

- **꾸준함**: 오늘의 테스트를 연속 5일 이상 응시
- **실력**: 최근 오늘의 테스트 5회 평균 정답률 90% 이상

학생 화면에는 두 조건의 진행 상황이 막대그래프로 표시되고, 조건을 모두 채우면 "자격 기준을 모두 채웠어요!"
문구와 함께 승급 시험 버튼이 열립니다. 미달 상태에서는 서버에서도 시험 시작 요청을 거부합니다(우회 불가).

## 페이지 구성

- `/` — 학생 로그인 (이름 + 4~6자리 숫자 비밀번호)
- `/student` — 학생 대시보드: 오늘의 테스트, 승급 시험, 최근 기록
- `/admin` — 선생님 관리자 페이지: 학생 등록/삭제/PIN 재설정/단계 직접 조정, **레벨업 보상 지급 체크리스트**
  (관리자 비밀번호는 `ADMIN_PASSWORD` 환경변수로 설정)
- `/board` — 교실에 띄워두는 **레벨업 게시판** (로그인 불필요, 10초마다 자동 새로고침)
  - 영어 레벨 게시판처럼 단계별로 학생 이름을 보여주고, 최근 레벨업 소식 & 보상 지급 여부를 표시합니다.
- `/report?id=학생ID` — **학부모 리포트** (관리자 로그인 필요, `/admin`의 학생 상세 화면에서 "학부모 리포트
  보기" 버튼으로 이동): 현재 단계, 연속 출석일, 승급 자격 진행 상황, 최근 오늘의 테스트 성적 추이, 레벨업/보상
  이력을 한 페이지로 정리해 인쇄(또는 PDF 저장)해서 학부모에게 보여줄 수 있습니다.

## 기술 스택

- Next.js (App Router) + TypeScript
- Prisma + Postgres (Neon / Vercel Postgres / Supabase 등 아무 호스팅 Postgres나 가능)
- 인증: 서명된 쿠키 기반 세션 (서버 메모리를 쓰지 않아 Vercel 서버리스 환경에서도 동작)
  - 학생: 이름 + PIN 로그인 → 서명된 학생 ID 쿠키
  - 관리자: `ADMIN_PASSWORD` 환경변수와 비교 → 서명된 관리자 쿠키
- 시험 문제/정답은 서버 비밀키(`SESSION_SECRET`)로 암호화한 토큰(`examToken`)에 담아 클라이언트에 내려주고,
  제출 시 그 토큰을 그대로 돌려받아 복호화해서 채점합니다. 서버리스 함수는 "시험 시작"과 "시험 제출"이 서로
  다른 인스턴스일 수 있어 메모리에 정답을 들고 있을 수 없기 때문입니다 — 토큰은 서버 비밀키 없이는 복호화할
  수 없으므로 클라이언트가 정답을 알아낼 수 없습니다.

## 로컬에서 실행하기

이 프로젝트는 Postgres가 필요합니다. 로컬 Postgres(또는 무료 Neon 등)를 하나 준비하고:

```bash
npm install
cp .env.example .env      # DATABASE_URL / ADMIN_PASSWORD / SESSION_SECRET 채우기
npx prisma migrate dev --name init   # 테이블 생성 (최초 1회)
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 → 학생 로그인 화면. 관리자 페이지는 `http://localhost:3000/admin`
(`.env`의 `ADMIN_PASSWORD`로 로그인). 처음에는 학생이 없으니 관리자 페이지에서 먼저 학생을 등록하세요.

## 배포하기 (Vercel, 무료)

1. **GitHub 저장소 연결**: [vercel.com](https://vercel.com) 로그인 → **Add New → Project** →
   이 저장소(`jung-ys/mymath`) 선택 → 브랜치는 `claude/multiplication-level-system-5bef6t`
   (또는 main에 병합했다면 main) 선택
2. **Postgres 만들기**: 프로젝트 생성 화면(또는 생성 후 **Storage** 탭)에서
   **Create Database → Postgres(Neon)** 선택. 무료 티어로 충분합니다. 만들면 `DATABASE_URL`
   환경변수가 자동으로 추가돼요.
3. **환경변수 설정**: **Settings → Environment Variables**에서 아래 두 개를 추가해주세요.
   - `ADMIN_PASSWORD`: 원하는 관리자 비밀번호
   - `SESSION_SECRET`: 임의의 긴 문자열 (`openssl rand -hex 32` 등으로 생성)
4. **Deploy** 클릭. 빌드 중 `prisma migrate deploy`가 자동 실행되어 테이블이 만들어집니다.
5. 배포된 주소로 접속해서 `/admin`에 로그인한 뒤, 학생을 등록하면 바로 사용할 수 있습니다.

### 비용

- **Vercel**: Hobby(무료) 플랜으로 충분한 트래픽 규모입니다 (학원 학생 수십 명 기준).
- **Neon Postgres**: 무료 티어로 충분합니다 (데이터 용량이 매우 작음 — 텍스트 위주 기록).
- 즉, 이미 Vercel 계정이 있다면 **추가 비용 없이** 배포할 수 있습니다.

## 채점 관련

워크시트(종이) 방식은 매번 선생님이 채점해야 하는 부담이 있습니다. 이 시스템은:

1. **자동 채점**: 학생이 답을 입력하고 제출하면 즉시 채점되고, 승급 여부도 자동으로 판정됩니다.
2. **집에서도 응시 가능**: 학생이 본인 이름 + 비밀번호로 로그인해 "오늘의 테스트"를 매일 볼 수 있고,
   연속 응시일(스트릭)이 기록되어 동기부여가 됩니다.
3. **학원에서는 승급 시험만 감독**: 매일 테스트는 집에서, 단계를 올리는 승급 시험은 학원에서 선생님이
   지켜보는 가운데 보게 하면 신뢰도와 공정성을 둘 다 챙길 수 있습니다.
4. **게시판으로 사기 진작**: `/board`를 교실 모니터/키오스크에 띄워두면 영어 레벨 게시판처럼
   누가 몇 단계인지, 누가 최근에 레벨업했는지 보여줄 수 있습니다.
5. **학부모 피드백**: 관리자 페이지에서 학생별로 매일 응시 기록·정확도 추이·승급 이력을 바로 확인할 수 있고,
   `/report`에서 한 장짜리 리포트로 인쇄/PDF 저장해 학부모에게 공유할 수 있습니다.

## 보안 참고

- 학생 비밀번호(PIN)는 salt + scrypt로 해시하여 DB에 저장합니다.
- 로그인 세션은 서버 상태 없이 **서명된 쿠키**로 검증합니다(`SESSION_SECRET`으로 HMAC 서명). 값을 위조하려면
  `SESSION_SECRET`을 알아야 하므로, 이 값은 외부에 노출되지 않도록 관리하세요.
- `ADMIN_PASSWORD`, `SESSION_SECRET`은 반드시 배포 환경에서 기본값이 아닌 값으로 설정하세요.
